## 4. هيكل الملفات

```
sana-website/
  PROJECT.md        ← الملف ده
  build.py          ← كل النصوص والصفحات (عربي + إنجليزي)
  worker/           ← سيرفر مساعد سنآ (Cloudflare Worker + Claude)
  make-preview.py   ← يعمل نسخة معاينة لـ claude.ai (مش مطلوب للنشر)
  brand/            ← اللوجو الأصلي ونسخة شفافة
  site/             ← الموقع الجاهز للنشر (ده اللي يترفع)
    styles.css      ← التصميم والألوان
    script.js       ← اللغة، قائمة الموبايل، الفورمات، رقم الواتساب
    assets/         ← اللوجو
    *.html          ← بتتولّد من build.py (متعدّلهاش بإيدك)
```

## 5. إزاي تعدّل

> **قاعدة مهمة:** ملفات `site/*.html` بتتولّد من `build.py`. أي تعديل في النصوص يتعمل في `build.py`، وبعدها شغّل:
>
> ```bash
> cd sana-website
> python3 build.py
> ```

| عايز تغيّر | فين |
|---|---|
| رقم التليفون أو الدومين | أول `build.py`: `PHONE_DISPLAY` و`PHONE_TEL` و`WHATSAPP` و`SITE_URL` |
| الرقم اللي الفورمات بتبعت عليه | أول `site/script.js`: `CONFIG.whatsapp` |
| الخدمات (عنوان، وصف، نقاط) | `SERVICES` في `build.py` |
| منتجات المتجر | `PRODUCTS` في `build.py` |
| أنواع المشاريع في "أعمالنا" | `WORK_TYPES` في `build.py` |
| نصوص أي صفحة | المتغيرات `home` و`about` و`services` و`work` و`store` و`careers` و`contact` في `build.py` |
| الألوان والخطوط | أول `site/styles.css` (`:root`) |
| اللوجو | حط الملف الجديد مكان `brand/logo-2026-source.png` وشغّل `python3 brand/make-logo.py` |

كل نص مكتوب بالشكل ده: `t("وسم", "النص العربي", "English text")`. لازم تعدّل اللغتين مع بعض.

**بعد أي تعديل:** افحص الموقع.

```bash
bash ../skills/company-website/scripts/check-site.sh site
```

والمفروض يطلّع `"errors": 0`.

**معاينة على جهازك:**

```bash
cd site
python3 -m http.server 8000
```

وبعدها افتح `http://localhost:8000`.

## 6. النشر على الدومين (sanatechgroup.online)

**الاستضافة:** Cloudflare Pages، وهي مجانية ومسموح فيها بالاستخدام التجاري.
**الدومين:** متسجّل في Namecheap.

إعدادات المشروع على Cloudflare Pages:

| الإعداد | القيمة |
|---|---|
| Repository | `sheryvip/vercel-labs-agent-skills` |
| Production branch | `claude/website-design-scale-kqln7a` (أو `main` بعد الدمج) |
| Framework preset | None |
| Build command | فاضي |
| Build output directory | `sana-website/site` |

الخطوات:

1. **حساب Cloudflare:** اعمل حساب على [dash.cloudflare.com](https://dash.cloudflare.com/sign-up).
2. **ضيف الدومين على Cloudflare:**
   - من الصفحة الرئيسية دوس **Add a domain** (أو Onboard a domain) واكتب `sanatechgroup.online`.
   - اختار الخطة **Free**.
   - Cloudflare هيدّيك **2 Nameservers**، مثلًا `xxx.ns.cloudflare.com` و`yyy.ns.cloudflare.com`. انسخهم.
3. **غيّر الـ Nameservers في Namecheap:**
   - ادخل Namecheap، وبعدين **Domain List**، وجنب `sanatechgroup.online` دوس **Manage**.
   - في خانة **Nameservers** اختار **Custom DNS**.
   - الزق الاتنين بتوع Cloudflare، ودوس ✓ للحفظ.
   - التفعيل بياخد من دقايق لحد 24 ساعة، وCloudflare هيبعتلك إيميل لما يخلص.
4. **اربط الموقع:**
   - في Cloudflare افتح **Workers & Pages**، ودوس **Create**، واختار تبويب **Pages**، وبعدين **Connect to Git** (أو Import an existing Git repository).
   - اربط GitHub، واختار المستودع، واكتب الإعدادات اللي في الجدول فوق.
   - دوس **Save and Deploy**. الموقع هيشتغل على رابط مؤقت زي `sana-website.pages.dev`.
5. **ضيف الدومين للموقع:**
   - من مشروع Pages افتح **Custom domains** ودوس **Set up a custom domain**.
   - اكتب `sanatechgroup.online` ودوس **Activate domain**.
   - كرر نفس الخطوة مع `www.sanatechgroup.online`.
   - Cloudflare بيعمل سجلات الـ DNS وشهادة HTTPS لوحده، طالما الـ Nameservers اتفعّلوا.
6. **اتأكد:**
   - افتح `https://sanatechgroup.online`.
   - جرّب زرار اللغة وفورم التواصل من الموبايل.
7. **بعد النشر:**
   - سجّل الموقع في [Google Search Console](https://search.google.com/search-console) كـ Domain property. التحقق بيتعمل بسجل TXT تضيفه في DNS بتاع Cloudflare.
   - ابعت `https://sanatechgroup.online/sitemap.xml`.
   - اعمل Google Business Profile بنفس الاسم والعنوان والرقم.

**التحديثات:** أي تعديل يترفع على الفرع اللي اخترته بيتنشر تلقائي خلال دقيقة تقريبًا.

**ملفات خاصة بـ Cloudflare:**
- `site/_headers`: إعدادات أمان وكاش.
- Cloudflare بيشيل `.html` من الروابط تلقائي، علشان كده الـ canonical وملف `sitemap.xml` مكتوب فيهم `/about` مش `/about.html`.

> لو الإيميل بتاع الدومين شغّال حاليًا من Namecheap (Private Email أو Email Forwarding): قبل ما تغيّر الـ Nameservers، اتأكد إن سجلات MX وTXT اتنقلت لـ Cloudflare. Cloudflare بينسخها لوحده وقت إضافة الدومين، بس راجعها في صفحة DNS.

**نصوص المميزات دي:**
- نصوص الأقسام في `build.py` (الدوال `quiz_section` و`before_after_section` و`calculator_section` و`chat_widget`، والقائمة `QUIZ`).
- ردود المساعد ومنطق الخطة في `site/script.js` (`SV` للخدمات، و`PRIMARY` و`SECOND` و`SIZE` و`PRIORITY` للاختبار).

### تشغيل مساعد سنآ بالذكاء الاصطناعي (Claude)

مفتاح الـ API **ممنوع يتحط في الموقع**. علشان كده بيتحط في Cloudflare Worker صغير، والموقع بيكلّم الـ Worker، والـ Worker بيكلّم Claude.

- **الكود:** `worker/src/index.js`
- **الملف الجاهز للصق:** `worker/dist/sana-chat-worker.js` (بيتعمل بـ `cd worker && npm install && npm run build`)
- **الموديل:** `claude-opus-5-5` بمجهود `low`، وده مناسب للشات.
- **أمان التكلفة:** الرد الواحد أقصاه 2048 token، وآخر 16 رسالة بس من المحادثة بتتبعت، والرسالة الواحدة أقصاها 1200 حرف.
- **لو الطلب اترفض:** فيه تحويل تلقائي لموديل تاني (`fallbacks: "default"`).
- **مين يقدر يستخدمه:** الـ Worker بيقبل الطلبات من `sanatechgroup.online` وروابط `sana*.pages.dev` بس.

الخطوات (من الكمبيوتر أسهل):
1. **مفتاح API:**
   - ادخل [console.anthropic.com](https://console.anthropic.com)، وبعدين **API Keys**، ودوس **Create Key**، وانسخه.
   - من **Settings ← Limits** حط **حد صرف شهري**، مثلًا 20 دولار.
2. **اعمل الـ Worker:**
   - في Cloudflare افتح **Workers & Pages**، ودوس **Create**، واختار **Create Worker**.
   - سمّيه `sana-chat`، ودوس **Deploy**.
   - دوس **Edit code**، وامسح الكود الموجود كله.
   - الزق محتوى `worker/dist/sana-chat-worker.js`، ودوس **Deploy**.
3. **حط المفتاح:**
   - من الـ Worker افتح **Settings ← Variables and Secrets**، ودوس **Add**.
   - النوع **Secret**، والاسم `ANTHROPIC_API_KEY`، والقيمة هي المفتاح. احفظ.
4. **اربطه بالموقع:**
   - انسخ رابط الـ Worker، شكله `https://sana-chat.xxxx.workers.dev`.
   - حطه في `site/script.js` في `CONFIG.workerUrl`. نفس الرابط ده بيشغّل المساعد وصفحة الأخبار مع بعض.
   - اعمل zip جديد وارفعه على Pages.
5. **(مستحسن) حد للطلبات:**
   - بعد ما الدومين يتفعّل على Cloudflare، اربط الـ Worker بدومين فرعي زي `chat.sanatechgroup.online` من **Settings ← Domains & Routes**.
   - اعمل قاعدة **Rate limiting** من **Security ← WAF**، مثلًا 20 طلب في الدقيقة لكل IP.
   - حدّث `CONFIG.workerUrl` بالرابط الجديد.

لو الـ Worker وقع أو مفيش رصيد، المساعد بيرجع لوحده للردود الموجّهة وزرار واتساب، والموقع ما بيقفش.

## 6.6 صفحة أخبار التقنية

- **إزاي بتشتغل:** نفس الـ Worker (`worker/src/news.js`) بيقرا خلاصات RSS الرسمية لـ 10 مصادر موثوقة على `GET /news`. بياخد العنوان وملخص قصير والتاريخ والصورة، ومعاهم رابط الخبر الأصلي.
- **التنظيف:** بيشيل الأخبار المكررة والأقدم من 30 يوم، وبيرتّب الأخبار من الأحدث للأقدم، وبيعلّم أخبار الذكاء الاصطناعي.
- **التحديث:** النتيجة بتتحفظ 15 دقيقة. يعني الصفحة بتتحدّث لوحدها كل ربع ساعة من غير ما حد يعمل حاجة.
- **المصادر:**
  - **عالمية:** MIT Technology Review، The Verge، TechCrunch، Ars Technica، WIRED، IEEE Spectrum، BBC News.
  - **عربية:** BBC عربي، البوابة العربية للأخبار التقنية، عالم التقنية.
- **إضافة أو شيل مصدر:** عدّل `FEEDS` في `worker/src/news.js`، وبعدها `NEWS_SOURCES` في `build.py` علشان قايمة "مصادرنا". اعمل build للـ Worker والصقه من جديد.
- **الصفحة في الموقع:**
  - فيها فلاتر: الكل، الذكاء الاصطناعي، بالعربي، بالإنجليزي.
  - كل خبر بيتكتب في اتجاه لغته.
  - بيظهر "آخر تحديث".
  - لو الـ Worker مش متركّب، الصفحة بتقرا `site/news.json` لو موجود (`cd worker && node scripts/snapshot.mjs`)، ولو مش موجود بتعرض روابط المصادر.
- **حقوق النشر:** بنعرض العنوان وملخص قصير بس، مع رابط واضح للمصدر، ومكتوب في الصفحة إن الحقوق لأصحابها.

## 7. المرحلة التانية — "جوه" الموقع (لسه متعملتش)

المطلوب:
- **لوحة تحكم:** تعدّل منها النصوص والصور، وتشوف طلبات العملاء وطلبات التوظيف في مكان واحد.
- **تسجيل دخول** بصلاحيات: أدمن، موظف، عميل.
- **متجر بدفع أونلاين** للأنظمة والـ AI Agent والبوتات، ودي ظاهرة حاليًا "قريبًا".

الخطة المقترحة:

| الجزء | التقنية | السبب |
|---|---|---|
| الموقع + لوحة التحكم | Next.js (App Router) على Vercel | نفس التصميم الحالي يتنقل كمكونات |
| قاعدة البيانات + تسجيل الدخول + الصور | Supabase (Postgres + Auth + Storage) | فيه خطة مجانية، والصلاحيات بتتحدد بـ Row Level Security |
| الدفع (مصر) | **Paymob** — فيزا، ميزة، محافظ إلكترونية، فوري | الأنسب للسوق المصري |
| إشعار الطلبات الجديدة | إيميل (Resend) أو رسالة واتساب للأدمن | — |

الخطوات بالترتيب:
1. نقل الصفحات الحالية لـ Next.js مع إن الشكل يفضل زي ما هو.
2. جداول قاعدة البيانات:
   - `leads` (طلبات الخدمة)
   - `applications` (التوظيف)
   - `store_waitlist`
   - `profiles` (المستخدمين والصلاحيات)
   - `content` (النصوص القابلة للتعديل)
   - `products` و`orders`
3. الفورمات تتسجل في قاعدة البيانات بدل ما تفتح واتساب، ونبعت إشعار للأدمن.
4. لوحة تحكم `/admin`: الطلبات، التوظيف، تعديل المحتوى، رفع الصور.
5. حسابات العملاء `/account`: الطلبات والمشتريات.
6. المتجر والدفع:
   - ربط Paymob محتاج حساب تاجر وسجل تجاري مصري ومفاتيح API.
   - المفاتيح بتتحط في إعدادات Vercel، **مش في الكود**.

## 9. سجل القرارات

- الخدمات الستة اقترحها Claude بناءً على "كل ما يخص التكنولوجيا"، وصاحب الشركة يقدر يعدّلها.
- "أعمالنا" بتعرض أنواع المشاريع بدل مشاريع مفبركة، لحد ما يكون فيه شغل حقيقي يتعرض.
- الوظائف: مفيش وظائف معلنة، وفيه فورم تقديم عام.
- الاستضافة: Cloudflare Pages (مجانية وتسمح بالاستخدام التجاري)، والدومين من Namecheap، والـ DNS هيتنقل لـ Cloudflare.
- الموقع حاليًا ثابت (HTML/CSS/JS) ومن غير سيرفر، علشان يتنشر بسرعة وببلاش. المرحلة التانية هتنقله لـ Next.js.
- الإيميل والسوشيال ومواعيد العمل اتشالوا بطلب صاحب الشركة.
