## 4. هيكل الملفات

```
sana-website/
  PROJECT.md        ← الملف ده
  build.py          ← كل النصوص والصفحات (عربي + إنجليزي)
  make-preview.py   ← يعمل نسخة معاينة لـ claude.ai (مش مطلوب للنشر)
  brand/            ← اللوجو الأصلي ونسخة شفافة
  site/             ← الموقع الجاهز للنشر (ده اللي يترفع)
    styles.css      ← التصميم والألوان
    script.js       ← اللغة، قائمة الموبايل، الفورمات، رقم الواتساب
    assets/         ← اللوجو
    *.html          ← بتتولّد من build.py (متعدّلهاش بإيدك)
```

## 5. إزاي تعدّل

> **قاعدة مهمة:** ملفات `site/*.html` بتتولّد من `build.py`. أي تعديل في النصوص يتعمل في `build.py`، وبعدها شغّل:
>
> ```bash
> cd sana-website
> python3 build.py
> ```

| عايز تغيّر | فين |
|---|---|
| رقم التليفون أو الدومين | أول `build.py`: `PHONE_DISPLAY` و`PHONE_TEL` و`WHATSAPP` و`SITE_URL` |
| الرقم اللي الفورمات بتبعت عليه | أول `site/script.js`: `CONFIG.whatsapp` |
| الخدمات (عنوان، وصف، نقاط) | `SERVICES` في `build.py` |
| منتجات المتجر | `PRODUCTS` في `build.py` |
| أنواع المشاريع في "أعمالنا" | `WORK_TYPES` في `build.py` |
| نصوص أي صفحة | المتغيرات `home` و`about` و`services` و`work` و`store` و`careers` و`contact` في `build.py` |
| الألوان والخطوط | أول `site/styles.css` (`:root`) |
| اللوجو | استبدل `site/assets/logo.png` (ارتفاعه 44px في الهيدر) |

كل نص مكتوب بالشكل ده: `t("وسم", "النص العربي", "English text")`. لازم تعدّل اللغتين مع بعض.

**بعد أي تعديل:** افحص الموقع.

```bash
bash ../skills/company-website/scripts/check-site.sh site
```

والمفروض يطلّع `"errors": 0`.

**معاينة على جهازك:**

```bash
cd site
python3 -m http.server 8000
```

وبعدها افتح `http://localhost:8000`.

## 6. النشر على الدومين (sanatechgroup.net)

1. اعمل مستودع GitHub خاص بالموقع (مثلًا `sana-website`) وانقل فيه فولدر `sana-website/`.
2. ادخل [vercel.com](https://vercel.com)، اعمل **New Project**، واختار المستودع.
   - **Root Directory:** `site` (أو `sana-website/site` لو فضل في المستودع ده)
   - **Framework:** Other، ومن غير build command
3. في Vercel افتح **Settings ← Domains** وضيف `sanatechgroup.net` و`www.sanatechgroup.net`.
4. عند الشركة اللي اشتريت منها الدومين، ضيف السجلات اللي Vercel هيعرضها. غالبًا هتكون:
   - `A` لـ `@` ← `76.76.21.21`
   - `CNAME` لـ `www` ← `cname.vercel-dns.com`
5. شهادة HTTPS بتطلع لوحدها. وبعد كده أي تعديل يترفع على GitHub بيتنشر تلقائي.
6. بعد النشر:
   - سجّل الموقع في Google Search Console وابعت `sitemap.xml`.
   - اعمل Google Business Profile بنفس الاسم والعنوان والرقم.

> ملحوظة: خطة Vercel المجانية (Hobby) للاستخدام الشخصي. موقع شركة غالبًا محتاج خطة Pro، فراجع شروطهم الحالية. البديل المجاني لموقع ثابت هو Cloudflare Pages أو Netlify.

## 7. المرحلة التانية — "جوه" الموقع (لسه متعملتش)

المطلوب:
- **لوحة تحكم:** تعدّل منها النصوص والصور، وتشوف طلبات العملاء وطلبات التوظيف في مكان واحد.
- **تسجيل دخول** بصلاحيات: أدمن، موظف، عميل.
- **متجر بدفع أونلاين** للأنظمة والـ AI Agent والبوتات، ودي ظاهرة حاليًا "قريبًا".

الخطة المقترحة:

| الجزء | التقنية | السبب |
|---|---|---|
| الموقع + لوحة التحكم | Next.js (App Router) على Vercel | نفس التصميم الحالي يتنقل كمكونات |
| قاعدة البيانات + تسجيل الدخول + الصور | Supabase (Postgres + Auth + Storage) | فيه خطة مجانية، والصلاحيات بتتحدد بـ Row Level Security |
| الدفع (مصر) | **Paymob** — فيزا، ميزة، محافظ إلكترونية، فوري | الأنسب للسوق المصري |
| إشعار الطلبات الجديدة | إيميل (Resend) أو رسالة واتساب للأدمن | — |

الخطوات بالترتيب:
1. نقل الصفحات الحالية لـ Next.js مع إن الشكل يفضل زي ما هو.
2. جداول قاعدة البيانات:
   - `leads` (طلبات الخدمة)
   - `applications` (التوظيف)
   - `store_waitlist`
   - `profiles` (المستخدمين والصلاحيات)
   - `content` (النصوص القابلة للتعديل)
   - `products` و`orders`
3. الفورمات تتسجل في قاعدة البيانات بدل ما تفتح واتساب، ونبعت إشعار للأدمن.
4. لوحة تحكم `/admin`: الطلبات، التوظيف، تعديل المحتوى، رفع الصور.
5. حسابات العملاء `/account`: الطلبات والمشتريات.
6. المتجر والدفع:
   - ربط Paymob محتاج حساب تاجر وسجل تجاري مصري ومفاتيح API.
   - المفاتيح بتتحط في إعدادات Vercel، **مش في الكود**.

المطلوب من صاحب الشركة قبل المرحلة دي:
- [ ] حساب Paymob (تاجر) — مطلوب سجل تجاري وبطاقة ضريبية
- [ ] حساب Supabase
- [ ] حساب Vercel
- [ ] أسعار المنتجات (النظام، الـ AI Agent، البوتات) ووصف كل منتج
- [ ] إيميل يستقبل إشعارات الطلبات
